Display & touch

Full-screen P1 touch lanes, left to right: Left, Down, Up, Right. Each lane covers one quarter of the screen width and its full height. Landscape and fullscreen are recommended. Audio starts after the explicit Start click. Fullscreen, orientation lock and wake lock depend on your browser.

Controller bindings

Connect a controller, then press and release a button to make it visible.

Standard pads: D-pad/stick, A/Start = Start, B/Back = Back. Use Map for dance pads and nonstandard controllers. All browser controls feed P1's native keyboard bindings; keyboard remains usable.

Local song library

Import original full SM songs, not a generated web package. Files stay in this browser's local storage and are never uploaded to a server. Static songs only; scripts/video/BGA extras are skipped. Only import files you trust.

32 MiB ZIP/file · 64 MiB per batch · 128 MiB local library. One UTF-8 .sm per song folder with OGG, MP3 or WAV music. Folder picking varies by browser; ZIP works on mobile.
